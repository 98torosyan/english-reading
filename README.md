# Ընթերցարան

Անգլերենի դասեր աշակերտների համար՝ 50 էսսե (10-ական A1, A2, B1, B2, C1), յուրաքանչյուրը ձայնով, 6 նոր բառով և 4 հարցով։
Ուսուցիչը մտնում է PIN-ով, ընտրում դասը և ուղարկում **Տեքստ**, **Ձայն** կամ **Միասին** կոճակով։

## Ֆայլեր
| Ֆայլ | Ինչ է անում |
|---|---|
| `index.html` | կայքը՝ ուսուցչի պանելը և աշակերտի դասի էջը |
| `essays.js` | բոլոր էսսեները, բառերը, հարցերը |
| `make_audio.py` | ստեղծում է MP3 ձայները (`audio/`) |
| `check_essays.py` | խիստ ստուգում է էսսեները մակարդակների կանոններով |
| `PROMPT.md` | պրոմպտը, որով գրվում են էսսեները |
| `.github/workflows/deploy.yml` | GitHub-ում ինքնաբերաբար ստեղծում է ձայները և հրապարակում կայքը |

## Նոր էսսե ավելացնել
1. `PROMPT.md`-ով գրիր էսսեն, `essays.js`-ում պատճենիր մեկ բլոկ և փոխիր դաշտերը (`id`-ն՝ լատինատառ, եզակի)։
2. Յուրաքանչյուր հարցի **առաջին պատասխանը ճիշտն է**, կայքը տարբերակներն ինքն է խառնում։
3. Push անես, և GitHub-ը ինքը կստուգի, կստեղծի նոր ձայնը և կթարմացնի կայքը։

## Ձայնը փոխել
`deploy.yml`-ում `python make_audio.py`-ը փոխիր `python make_audio.py --voice en-US-AvaNeural --force`-ի, մեկ անգամ push արա, հետո `--force`-ը հանիր։
