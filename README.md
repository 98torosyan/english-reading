# Gayane Torosyan | English Reading Room

Անգլերենի դասեր աշակերտների համար՝ 50 էսսե (10-ական A1, A2, B1, B2, C1), յուրաքանչյուրը ձայնով, 6 նոր բառով և 4 հարց։
Ուսուցիչը մտնում է PIN-ով, ընտրում դասը և ուղարկում **Տեքստ**, **Ձայն** կամ **Միասին** կոճակով։

## Ֆայլեր
| Ֆայլ | Ինչ է անում |
|---|---|
| `index.html` | կայքը՝ ուսուցչի պանելը և աշակերտի դասի էջը |
| `essays.js` | բոլոր էսսեները, բառերը, հարցերը |
| `dict.js` | բոլոր էսսեների ամեն բառի ստուգված հայերեն թարգմանությունը (աշակերտը սեղմում է ցանկացած բառի վրա) |
| `make_audio.py` | ստեղծում է MP3-երը՝ ♪ լոգո → վերնագիր → էսսե → «Gayane's Reading Room.» |
| `make_chime.py`, `brand/` | Գայանեի ձայնային լոգոն (3 զանգակային նոտա) |
| `build_pages.py` | ստեղծում է չատի քարտերը (`l/`, `og/`) |
| `check_essays.py` | խիստ ստուգում է էսսեները մակարդակների կանոններով |
| `tests/` | քաոսային թեստեր (Python և կայքի համար) |
| `icon.svg`, `logo.svg`, `*.png` | լոգոն և պատկերակները |
| `PROMPT.md` | պրոմպտը, որով գրվում են էսսեները |
| `.github/workflows/deploy.yml` | ստուգում է ամեն ինչ, ստեղծում ձայներն ու քարտերը, հրապարակում կայքը |

## Նոր էսսե ավելացնել
1. `PROMPT.md`-ով գրիր էսսեն, `essays.js`-ում պատճենիր մեկ բլոկ և փոխիր դաշտերը (`id`-ն՝ լատինատառ, եզակի)։
2. Յուրաքանչյուր հարցի **առաջին պատասխանը ճիշտն է**, կայքը տարբերակներն ինքն է խառնում։
3. Push անես, և GitHub-ը ինքը կստուգի, կստեղծի ձայնն ու քարտը և կթարմացնի կայքը։ Եթե որևէ թեստ չանցնի, կայքը չի թարմանա, և Actions-ում կերևա պատճառը։

## Ձայնը փոխել
`make_audio.py`-ում փոխիր `VERSION`-ը (օր.՝ `"v3"`), կամ `--voice en-US-AvaNeural`-ը ավելացրու `deploy.yml`-ի `python make_audio.py`-ին։ Բոլոր ձայները նորից կստեղծվեն։

## PIN
Գաղտնի PIN-ը պահվում է GitHub-ում՝ Settings → Secrets → `TEACHER_PIN`։ Փոխելու համար թարմացրու այն և Actions → Run workflow։

## Աշակերտի էջում (index.html)
- **Սեղմիր ցանկացած բառի վրա** տեքստում՝ հայերեն թարգմանություն (դասի 6 բառը՝ անմիջապես և ճշգրիտ, մնացածը՝ ավտոմատ թարգմանությամբ՝ MyMemory, անվճար) + անգլերեն բացատրություն + արտասանություն։
- **YouTube-ի նման ձայնային գիծ.** քաշիր ժամանակագիծը, ±10 վրկ, նախորդ/հաջորդ նախադասություն, կրկնել նախադասությունը, արագություն։ Գծի վրա նշված են նախադասությունների սկիզբները։
- **☀/☾ կոճակ.** ցերեկային և գիշերային ռեժիմ (սկզբում հետևում է հեռախոսին, ընտրությունը հիշվում է)։ Տառաչափը և տառատեսակը ֆիքսված են ընթերցանության համար լավագույն արժեքներով։
- MyMemory-ի օրական սահմանաչափը (5000 նիշ) յուրաքանչյուր աշակերտի IP-ի համար առանձին է։ Եթե ուզում ես 10 անգամ ավելի, `index.html`-ում `MYMEMORY_EMAIL = ""`-ի մեջ գրիր քո email-ը։

## Նոր էսսե ավելացնելիս
Եթե նոր էսսեում կա բառ, որը `dict.js`-ում չկա, կայքը այդ բառի համար թարգմանություն ցույց չի տա։ Ուղարկիր նոր էսսեն Claude-ին և խնդրիր ավելացնել պակասող բառերը `dict.js`-ում։
